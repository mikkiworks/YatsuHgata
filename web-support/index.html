Web Support ホームページ制作・更新のご相談

お店や活動の情報を、わかりやすく伝えるお手伝い。

新しくホームページを作りたい。今あるページの情報を更新したい。スマートフォンでも見やすくしたい。

ホームページの新規制作・更新・修正などのご相談を承ります。地域のお店・事業者・団体の皆さまをはじめ、個人の活動についても、目的やご予算に合わせてご提案します。

制作・更新について相談する

このようなお困りごとはありませんか？

  • お店や活動を紹介するホームページがほしい
  • 営業時間や料金、写真などの情報を変更したい
  • スマートフォンで見ると文字が小さく、読みにくい
  • ページの内容を整理して、必要な情報を伝えやすくしたい
  • 更新を頼める相手がいない

新規制作だけでなく、既存サイトの修正や、一部のページの更新についてもご相談ください。

お手伝いできること

ホームページの新規制作

お店・事業・団体・個人の活動などを紹介するホームページを制作します。掲載する情報の整理から、ページ構成、デザイン、公開までお手伝いします。

既存ホームページの更新・修正

文章や写真の差し替え、営業時間・料金の変更、お知らせの掲載などに対応します。

既存サイトの仕組みや管理状況によっては、対応が難しい場合があります。まずはサイトのURLとご希望をお知らせください。

見やすさ・使いやすさの改善

スマートフォンでの表示や文字の読みやすさ、情報の並び方、お問い合わせまでの導線などを見直します。

制作を担当する人

谷津干潟ナビを制作・運営しているMiKKiです。谷津エリアに暮らしながら、Webデザイナー・コーダーとして活動しています。

谷津干潟ナビの構成・デザイン・制作・更新を行っています。訪れる方に必要な情報が伝わるよう、情報の整理やスマートフォンでの読みやすさを考え、改善を重ねています。ホームページについてのご相談も、私が直接お伺いします。

管理人について詳しく見る

ご相談から公開まで

  1. お問い合わせ
    ご希望やお困りごとをお知らせください。内容がまとまっていなくても大丈夫です。
  2. 内容の確認・お見積もり
    対応範囲や必要な素材、スケジュールを確認し、お見積もりをご案内します。
  3. 制作・修正
    お見積もりや条件にご同意いただいてから、制作を進めます。文章や写真などは、ご相談のうえでご用意いただきます。
  4. ご確認・公開
    仕上がりをご確認いただき、必要な調整を行って公開します。

料金について

料金は、ページ数や作業内容によって異なります。ご希望を伺ったうえで、個別にお見積もりします。

ご予算が決まっている場合は、お問い合わせの際にお知らせください。ご希望とご予算に合わせて、対応する内容をご相談します。

お問い合わせ

新規制作から、文章・写真の差し替えなどの小さな更新まで、まずはご相談ください。

お問い合わせフォームの「お問い合わせ内容」に「Web制作・更新の相談」と書き、以下の内容をわかる範囲でお知らせください。

  • お名前・事業名や団体名
  • ご相談内容
  • 現在のホームページのURL（ある場合）
  • ご希望の時期
  • ご予算の目安（任意）

いただいた内容を確認し、メールでお返事します。
